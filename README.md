# BetterGitHub

Расширение для Chromium и Firefox, которое оформляет репозитории, профили пользователей и организации на GitHub. Настройки сохраняются автоматически; доступен каталог тем и независимые плагины интерфейса.
Выбранная личная тема применяется также к остальным страницам `github.com`.

## Установка для проверки

В PowerShell из этой папки:

```powershell
.\build.ps1
```

- **Chromium / Chrome / Edge:** откройте `chrome://extensions` (в Edge — `edge://extensions`), включите режим разработчика, нажмите «Загрузить распакованное» и выберите папку `dist/chromium` внутри клонированного проекта.
- **Firefox:** откройте `about:debugging#/runtime/this-firefox`, нажмите «Загрузить временное дополнение» и выберите файл `dist/firefox/manifest.json` внутри клонированного проекта. Временное дополнение исчезнет после перезапуска Firefox.

После повторной сборки перезагрузите расширение на странице расширений браузера и обновите вкладку GitHub, иначе браузер продолжит использовать старые файлы.

Значок BetterGitHub открывает компактную панель с двумя последними выбранными темами и карточкой «Выключить BetterGitHub». До первого выбора предлагаются «Светлая» и «Полночь». Выключение возвращает оформление GitHub, сохраняя настройки темы и её применения. Ниже можно выбрать «Моя тема везде» или «Тема автора страницы». «Магазин BetterGitHub» открывается в отдельной вкладке с каталогом тем и разделом плагинов. В «Дополнительно» можно изменить язык, палитру и источник оформления.

## Навигационные плагины

В панели расширения нажмите «Плагины»: откроется соответствующий раздел настроек. Каждый плагин включается отдельно и сразу сохраняется. Четыре новых плагина по умолчанию выключены; у каждого своя кнопка на GitHub и сочетание клавиш.

| Плагин | Действие | Клавиши |
|---|---|---|
| Command Palette | Поиск команд GitHub и включённых инструментов BetterGitHub | Ctrl/⌘ + Shift + Space |
| Quick Navigation | Переходы по вкладкам GitHub и заголовкам текущей страницы | Alt + Shift + G |
| Repository Switcher | Переход между недавними репозиториями или по введённому `owner/repo` | Alt + Shift + R |
| Quick Actions | Копирование ссылок и команд, открытие форм Issue и Pull Request | Alt + Shift + A |

В окнах работают поиск, ↑/↓, Enter и Esc. Сочетания не перехватываются при вводе текста. На узком экране отдельные кнопки находятся внизу справа. Quick Actions не отправляет формы, не создаёт коммиты и не выполняет скопированные команды.

Repository Switcher хранит в браузере последние 30 репозиториев GitHub: имя, время посещения и доступную отметку приватности. История не отправляется разработчику или на внешний сервер; «Очистить историю» удаляет её. Выключение плагина прекращает запись истории. Переключатель «Сохранять текущий раздел» позволяет, например, перейти из Issues одного репозитория в Issues другого. «Выключить BetterGitHub» приостанавливает всё расширение на GitHub, включая эти инструменты.

## Раздача Firefox через GitHub Releases

```powershell
.\build.ps1 -Target firefox -FirefoxSelfDistributed
npx --no-install web-ext build --source-dir dist/firefox-self --artifacts-dir dist/packages/firefox-self --overwrite-dest
```

Загрузите ZIP из `dist/packages/firefox-self` в Mozilla Developer Hub через
«Самостоятельно». Полученный после подписи `.xpi` прикрепите к GitHub Release.
Затем добавьте в [updates.json](updates.json) запись под
`addons["bettergithub@yarilafox"].updates` с полями `version` и `update_link`.
Укажите версию из подписанного пакета и прямую HTTPS-ссылку на его `.xpi`.
Для следующего релиза сначала увеличьте `version` в `manifest.firefox.json`.

Обычная сборка `.\build.ps1 -Target firefox` предназначена для публикации на AMO.

## Оформление страницы через JSON

На странице репозитория откройте шестерёнку About и выберите «Оформление BetterGitHub»; на странице профиля нажмите BetterGitHub под его основной кнопкой. Настройте оформление и выберите «Открыть в GitHub» или «Файл профиля в GitHub». Расширение подготовит JSON в веб-редакторе; проверьте содержимое и нажмите GitHub «Commit changes». Если автоматическая вставка не сработала, на странице редактора есть «Скопировать JSON» для вставки вручную. Кнопка «Сохранить локально» записывает настройки только в браузер. Существующий `bettergithub.json` или `.bettergithub.json` редактируется под прежним именем; новый `.bettergithub.json` создаётся только при отсутствии обоих. Образец: [`examples/.bettergithub.json`](examples/.bettergithub.json).

Для профиля пользователя файл физически лежит в репозитории `USERNAME/USERNAME`, но его настройки находятся в разделе `profile` внутри JSON. Корневые поля того же файла остаются настройками страницы репозитория. Для организации файл лежит в `ORG/.github`, а настройки организации находятся в разделе `organization`. Старые JSON без этих разделов продолжают читаться. Если GitHub покажет организацию как обычный профиль, расширение также попробует `ORG/.github` после `ORG/ORG`.

На странице организации кнопка BetterGitHub открывает её оформление. «Сохранить тему организации в GitHub» направляет в `.bettergithub.json` репозитория `ORG/.github`, сохраняя остальные разделы существующего файла. Если публичный репозиторий недоступен, расширение сохраняет черновик темы и открывает создание публичного `.github`: подтвердите владельца, включите README и создайте репозиторий, затем нажмите «Продолжить сохранение темы». Расширение подготовит JSON в редакторе; коммит подтверждается вами на GitHub. Черновик для продолжения доступен 20 минут. README главной страницы организации создаётся отдельно в `profile/README.md`.

Поддерживаются:

- `appearance.theme`: `github`, `compact`, `compact-light`, `rounded`, `rounded-light`, `universe`, `universe-dark`, `midnight`, `amethyst`, `forest` или `light`;
- `appearance.accent`, `base`, `surface`, `text`, `muted`, `border`: цвета вида `#RRGGBB`;
- `appearance.background`: фоновое изображение;
- `appearance.effect`: `none`, `gradient` или `glow`;
- `banner`: изображение над About (или над заголовком профиля);
- `icon`: значок рядом с названием;
- `installUrl`: прямая HTTPS-ссылка на файл GitHub Release;
- `layout.sidebar`: порядок блоков `about`, `releases`, `packages`, `contributors`, `languages`.
- `layout.profile`: порядок блоков профиля `readme`, `pinned`, `contributions`;
- `layout.profileSidebar`: порядок блоков профиля слева `info`, `achievements`, `highlights`.

Для изображений можно указать путь относительно корня репозитория с JSON, например `assets/banner.png`. Можно также указать HTTPS-адрес на `github.com`, `raw.githubusercontent.com` или `*.githubusercontent.com`. Прочие адреса и схемы игнорируются. Ссылка установки принимается только на путь `github.com/OWNER/REPO/releases/download/...` или `releases/latest/download/...`. **Кнопка Code меняется только при явно заданном `installUrl`** в JSON или личной настройке страницы.

Вариант «Моя тема для всех страниц» в настройках расширения использует личные цвета и фон вместо `appearance` из JSON. Баннер, значок, ссылка установки и порядок блоков продолжают работать. На странице репозитория редактор доступен из окна штатной шестерёнки About только тем, кто может редактировать сведения репозитория, если включён соответствующий плагин. На странице профиля кнопка BetterGitHub находится под его основной кнопкой. Цвета выбираются во встроенном редакторе с HEX-полем и ползунками. Выбор темы сразу показывает предпросмотр; для личного сохранения нажмите «Сохранить локально», а закрытие панели возвращает прежнюю тему. На странице профиля нажмите BetterGitHub: ручки из шести точек появятся у блоков README, Pinned и Contributions справа, а также у информации профиля, Achievements и Highlights слева. Перетащите ручку блока на другой блок в той же колонке или используйте стрелки ↑/↓, затем нажмите «Файл профиля в GitHub» и подтвердите коммит, чтобы показать расположение другим пользователям. Расширение пытается вставить JSON в редактор один раз и после этого не меняет файл во время вашего редактирования. «Отмена» убирает ручки и возвращает прежний порядок.

Темы `universe` и `universe-dark` вдохновлены [GitHub Universe](https://githubuniverse.com/): шрифты Mona Sans и Mona Sans Mono, контрастная типографика, зелёные акценты и пиксельный шлейф цветных символов за курсором в области контента. На вкладках репозитория при наведении кратко появляются разные наборы символов; родные подписи GitHub при этом не меняются. Тема не добавляет рекламный баннер. Файлы шрифтов распространяются по лицензии SIL OFL 1.1, копия: [`fonts/OFL.txt`](fonts/OFL.txt). При системной настройке «уменьшить движение» анимация отключается.

Расширение принимает только перечисленные цвета, ссылки и эффекты. Оно не выполняет CSS или JavaScript из JSON. Публичные файлы оформления читаются с `raw.githubusercontent.com`, поэтому лимит неавторизованных запросов к GitHub API не прерывает загрузку темы. После перехода из редактора GitHub на страницу файла расширение сбрасывает кэш и обновляет открытые страницы. При других способах изменения JSON ответ кэшируется до пяти минут.

В Firefox дополнение сообщает о передаче адресов открытых репозиториев GitHub: оно читает публичный JSON с `raw.githubusercontent.com`, а GitHub API или страницу репозитория использует для определения основной ветки при открытии редактора. Другие сайты и собственные серверы расширения не используются.
