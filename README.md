# BetterGitHub

Расширение для Chromium и Firefox, которое оформляет репозитории, профили пользователей и организации на GitHub. Это первая рабочая версия.
Выбранная личная тема применяется также к остальным страницам `github.com`.

## Установка для проверки

В PowerShell из этой папки:

```powershell
.\build.ps1
```

- **Chromium / Chrome / Edge:** откройте `chrome://extensions` (в Edge — `edge://extensions`), включите режим разработчика, нажмите «Загрузить распакованное» и выберите папку `dist/chromium` внутри клонированного проекта.
- **Firefox:** откройте `about:debugging#/runtime/this-firefox`, нажмите «Загрузить временное дополнение» и выберите файл `dist/firefox/manifest.json` внутри клонированного проекта. Временное дополнение исчезнет после перезапуска Firefox.

После повторной сборки перезагрузите расширение на странице расширений браузера и обновите вкладку GitHub, иначе браузер продолжит использовать старые файлы.

Значок BetterGitHub открывает компактную панель с двумя последними выбранными темами и карточкой «Выключить тему». До первого выбора предлагаются «Светлая» и «Полночь». Выключение возвращает оформление GitHub, сохраняя настройки темы и её применения. Ниже можно выбрать «Моя тема везде» или «Тема автора страницы». «Магазин BetterGitHub» открывается в отдельной вкладке с каталогом тем и разделом плагинов. В «Дополнительно» можно изменить язык, палитру и источник оформления.

## Раздача Firefox через GitHub Releases

```powershell
.\build.ps1 -Target firefox -FirefoxSelfDistributed
npx --no-install web-ext build --source-dir dist/firefox-self --artifacts-dir dist/packages/firefox-self --overwrite-dest
```

Загрузите ZIP из `dist/packages/firefox-self` в Mozilla Developer Hub через
«Самостоятельно». Полученный после подписи `.xpi` прикрепите к GitHub Release.
Затем добавьте в [updates.json](updates.json) запись под
`addons["bettergithub@yarilafox"].updates` с полями `version` и `update_link`.
Укажите версию из подписанного пакета и прямую HTTPS-ссылку на его `.xpi`.
Для следующего релиза сначала увеличьте `version` в `manifest.firefox.json`.

Обычная сборка `.\build.ps1 -Target firefox` предназначена для публикации на AMO.

## Оформление страницы через JSON

Откройте страницу репозитория или профиля, нажмите «✦ BetterGitHub», настройте оформление и выберите «Открыть в GitHub» или «Файл профиля в GitHub». Расширение подготовит JSON в веб-редакторе; проверьте содержимое и нажмите GitHub «Commit changes». Если автоматическая вставка не сработала, на странице редактора есть «Скопировать JSON» для вставки вручную. Кнопка «Сохранить локально» записывает настройки только в браузер. Существующий `bettergithub.json` или `.bettergithub.json` редактируется под прежним именем; новый `.bettergithub.json` создаётся только при отсутствии обоих. Образец: [`examples/.bettergithub.json`](examples/.bettergithub.json).

Для профиля пользователя файл физически лежит в репозитории `USERNAME/USERNAME`, но его настройки находятся в разделе `profile` внутри JSON. Корневые поля того же файла остаются настройками страницы репозитория. Для организации файл лежит в `ORG/.github`, а настройки организации находятся в разделе `organization`. Старые JSON без этих разделов продолжают читаться. Если GitHub покажет организацию как обычный профиль, расширение также попробует `ORG/.github` после `ORG/ORG`.

Поддерживаются:

- `appearance.theme`: `github`, `universe`, `universe-dark`, `midnight`, `amethyst`, `forest` или `light`;
- `appearance.accent`, `base`, `surface`, `text`, `muted`, `border`: цвета вида `#RRGGBB`;
- `appearance.background`: фоновое изображение;
- `appearance.effect`: `none`, `gradient` или `glow`;
- `banner`: изображение над About (или над заголовком профиля);
- `icon`: значок рядом с названием;
- `installUrl`: прямая HTTPS-ссылка на файл GitHub Release;
- `layout.sidebar`: порядок блоков `about`, `releases`, `packages`, `contributors`, `languages`.
- `layout.profile`: порядок блоков профиля `readme`, `pinned`, `contributions`;
- `layout.profileSidebar`: порядок блоков профиля слева `info`, `achievements`, `highlights`.

Для изображений можно указать путь относительно корня репозитория с JSON, например `assets/banner.png`. Можно также указать HTTPS-адрес на `github.com`, `raw.githubusercontent.com` или `*.githubusercontent.com`. Прочие адреса и схемы игнорируются. Ссылка установки принимается только на путь `github.com/OWNER/REPO/releases/download/...` или `releases/latest/download/...`. **Кнопка Code меняется только при явно заданном `installUrl`** в JSON или личной настройке страницы.

Вариант «Моя тема для всех страниц» в настройках расширения использует личные цвета и фон вместо `appearance` из JSON. Баннер, значок, ссылка установки и порядок блоков продолжают работать. Отдельная кнопка «✦ BetterGitHub» возле названия репозитория или под именем профиля открывает меню оформления; штатная шестерёнка About по-прежнему редактирует сведения GitHub. Цвета выбираются во встроенном редакторе с HEX-полем и ползунками. Выбор темы сразу показывает предпросмотр; для личного сохранения нажмите «Сохранить локально», а закрытие панели возвращает прежнюю тему. На странице профиля нажмите «✦ BetterGitHub»: ручки из шести точек появятся у блоков README, Pinned и Contributions справа, а также у информации профиля, Achievements и Highlights слева. Перетащите ручку блока на другой блок в той же колонке или используйте стрелки ↑/↓, затем нажмите «Файл профиля в GitHub» и подтвердите коммит, чтобы показать расположение другим пользователям. Расширение пытается вставить JSON в редактор один раз и после этого не меняет файл во время вашего редактирования. «Отмена» убирает ручки и возвращает прежний порядок.

Темы `universe` и `universe-dark` вдохновлены [GitHub Universe](https://githubuniverse.com/): шрифты Mona Sans и Mona Sans Mono, контрастная типографика, зелёные акценты и пиксельный шлейф цветных символов за курсором в области контента. На вкладках репозитория при наведении кратко появляются разные наборы символов; родные подписи GitHub при этом не меняются. Тема не добавляет рекламный баннер. Файлы шрифтов распространяются по лицензии SIL OFL 1.1, копия: [`fonts/OFL.txt`](fonts/OFL.txt). При системной настройке «уменьшить движение» анимация отключается.

Расширение принимает только перечисленные цвета, ссылки и эффекты. Оно не выполняет CSS или JavaScript из JSON. Публичные файлы оформления читаются с `raw.githubusercontent.com`, поэтому лимит неавторизованных запросов к GitHub API не прерывает загрузку темы. После перехода из редактора GitHub на страницу файла расширение сбрасывает кэш и обновляет открытые страницы. При других способах изменения JSON ответ кэшируется до пяти минут.

В Firefox дополнение сообщает о передаче адресов открытых репозиториев GitHub: оно читает публичный JSON с `raw.githubusercontent.com`, а GitHub API или страницу репозитория использует для определения основной ветки при открытии редактора. Другие сайты и собственные серверы расширения не используются.
