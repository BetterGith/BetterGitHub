BetterGitHub

Выбери тему

Выбери карточку и сохрани настройки, чтобы применить тему ко всему GitHub.

Дополнительные настройки ↗

Можно использовать оформление из .bettergithub.json на отдельных страницах или настроить личную тему для всего GitHub.

Цвета моей темы

Выбери карточку выше и измени её цвета под себя. Выбор другой карточки вернёт цвета её палитры.

Изображения загружаются только с GitHub. CSS и JavaScript из файлов оформления не выполняются.
